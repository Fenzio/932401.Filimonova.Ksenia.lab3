# 932401.Filimonova.Ksenia.lab3

## О себе — Искусство и креатив

Лабораторная работа №3. Flexbox, CSS Grid, медиа-запросы и адаптивная вёрстка.

**Автор:** Филимонова Ксения, группа 932401

## Что реализовано

- Flexbox: горизонтальное адаптивное меню навигации
- Flexbox: карточки «Хобби» (4 шт.) с выравниванием `align-items: center`
- CSS Grid: галерея «Любимые места» (3×2 на десктопе, 2 — планшет, 1 — мобильный)
- Медиа-запросы `@media (max-width: 1023px)` и `@media (max-width: 767px)`
- Отсутствие горизонтальной прокрутки на любом разрешении
- Контраст текста поверх фото ≥ 4.5:1 (тёмный градиент + белый текст с тенью)
- Семантика: `<figure>` + `<figcaption>` для мест, `<article>` для хобби
- Атрибут `lang="ru"` на описаниях
- CSS-переменные в `:root` для цветов и шрифтов
- Три способа подключения стилей: внешний, внутренний `<style>`, inline
- Позиционирование: `static`, `relative`, `absolute`
- Состояния элементов: `:hover`, `:active`, `:focus`, `:visited`
- Подсветка активной секции при скролле (`.scroll-section.active`)
- Чёткая белая рамка 3px вокруг кнопки при `:focus` + тёмное свечение
- Иконка «Избранное» в углу карточки проекта (`position: absolute`)
- Моноширинный шрифт и внутренняя тень у `textarea`
